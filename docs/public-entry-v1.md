# 公开入口 v1

访客直接访问 `/`，可阅读产品说明、工作方式、判断边界、一组原创静态双侧证据和既有使用指南，也可以直接进入默认空的工作区。会话正在确认、未登录或确认失败时，公开页与空工作区均立即显示；访客浏览只允许既有的 `/api/v1/auth/me` 会话探测，不请求项目、目录、文档、运行或模型配置等私密数据，也不创建匿名账户或样例项目。

## 入口与登录提醒

| 入口 | 目标页面 | 行为 |
| --- | --- | --- |
| 进入工作区 | `/app` | 无需登录，直接浏览空项目中心 |
| 新建故事项目 | `/app` | 提示登录后，由作者自行创建 |
| 导入已有故事 | `/app` | 提示登录后，由作者自行选择文件并导入 |
| 模型与密钥 | `/app/settings/model` | 提示登录后，由作者自行配置或测试 |

“进入工作区”和空工作区栏目导航是浏览操作，不弹登录提醒。新建、导入、选择文件、处理文稿、校验、创建样例、生成图/时间线、提交反馈、导出及模型/账户配置等实际功能，才在当前页打开原生 `dialog`，标题为“登录后继续”，说明该操作需要账户的原因。登录与注册链接通过既有 `safeReturnTo` 保留合法内部目标。提醒不保留待执行动作，认证成功仅导航，不自动创建、导入、分析或调用模型。

## 空工作区浏览

`GuestWorkspace` 复用既有项目中心的外壳、导航与空白态样式，使用本地静态信息。允许的无资源编号路径为 `/app`、`/check`、`/projects`、`/characters`、`/diff`、`/revision`、`/visual`、`/audit`、`/report`，可通过按钮与浏览器前进/后退切换。路径白名单精确匹配并允许尾斜线；查询参数和片段不会加载项目或运行，也不随访客实际功能入口传入认证后的目标。

空项目中心没有个人目录，其他栏目没有文稿、角色、版本、运行或报告。访客组件不挂载 `ProjectCenter`/`WorkspaceApp` 私密业务 hooks，不使用文件选择器、可编辑文稿、账户草稿或浏览器暂存，不发起任何业务写入。登录后自行选项目、输入或选择文件，实际执行前仍遵循原业务流程。

“继续浏览”“关闭登录提醒”、Escape 和点击背景均关闭提醒，保持原页面与阅读位置，并将焦点交还触发按钮。对话框提供可见键盘焦点与 Tab 边界循环。

确认会话期间可浏览空工作区；功能提醒显示“确认完成前不能使用个人功能”，暂时禁用登录和注册按钮。RootApp 的探测最长等待 4 秒。失败或超时后，访客仍可阅读、手动重试或前往登录/注册。重试、登录成功、注销、会话失效及卸载会中止旧请求或使请求代次失效，迟到响应不能覆盖新的身份决定。

## 兼容与权限边界

- 已登录用户与服务明确返回的本地 `anonymous` 模式，访问 `/` 仍自动进入 `/app`。
- 未登录直接访问白名单无编号栏目时展示空工作区；带项目/运行编号的深链、账户/模型设置及旧 `/provider` 路径继续使用原登录保护与安全回跳。会话确认失败时不挂载私密页面；认证页可以独立尝试登录或注册。
- 登录与注册页均提供“返回公开首页”。认证页切换和认证成功继续沿用 `safeReturnTo`。
- `SESSION_EXPIRED` 处理、账户草稿绑定、过期暂挂及主动退出清理保持原有政策。
- 不改变服务端权限、API 客户端、`AUTH_MODE`、浏览器暂存政策，不新增生产匿名模式。空工作区只提供静态浏览。服务端仅补齐 `/characters` 与 `/revision` 的 SPA 静态刷新白名单，不放开 API、资源、未知子路径或穿越路径。
