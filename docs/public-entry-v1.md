# 公开入口 v1

访客直接访问 `/`，可阅读产品说明、工作方式、判断边界、一组原创静态双侧证据和既有使用指南。会话正在确认、未登录或确认失败时，首页均立即显示；公开阅读只允许既有的 `/api/v1/auth/me` 会话探测，不请求项目、目录、模型配置等私密数据，也不创建样例项目。

## 入口与登录提醒

| 公开入口 | 登录或注册后的页面 | 后续操作 |
| --- | --- | --- |
| 进入工作区 | `/app` | 作者选择项目 |
| 新建故事项目 | `/app` | 作者自行创建 |
| 导入已有故事 | `/app` | 作者自行选择文件并导入 |
| 模型与密钥 | `/app/settings/model` | 作者自行配置或测试 |

上述入口在公开页内打开原生 `dialog`，标题为“登录后继续”，说明该操作需要账户的原因。登录与注册链接通过既有 `safeReturnTo` 保留合法内部目标。提醒不保留待执行动作，认证成功仅导航，不自动创建、导入、分析或调用模型。

“继续浏览”“关闭登录提醒”、Escape 和点击背景均关闭提醒，保持原页面与阅读位置，并将焦点交还触发按钮。对话框提供可见键盘焦点与 Tab 边界循环。

确认会话期间，提醒显示明确状态，暂时禁用登录和注册按钮；RootApp 的探测最长等待 4 秒。失败或超时后，访客仍可阅读、手动重试或前往登录/注册。重试、登录成功、注销、会话失效及卸载会中止旧请求或使请求代次失效，迟到响应不能覆盖新的身份决定。

## 兼容与权限边界

- 已登录用户与服务明确返回的本地 `anonymous` 模式，访问 `/` 仍自动进入 `/app`。
- 未登录直接访问 `/app`、工作台或账户/模型设置深链，继续使用原登录保护与安全回跳。会话确认失败时不挂载私密页面；认证页可以独立尝试登录或注册。
- 登录与注册页均提供“返回公开首页”。认证页切换和认证成功继续沿用 `safeReturnTo`。
- `SESSION_EXPIRED` 处理、账户草稿绑定、过期暂挂及主动退出清理保持原有政策。
- 不改变服务端权限、API 客户端、`AUTH_MODE`、浏览器暂存政策，不新增公开工作台或生产匿名模式。

## 设计与验证

沿用 `design-system/loreguard/MASTER.md` 的星轨书斋令牌，使用安静实色主操作、连续内容与分隔线。书灵仅出现在欢迎区；静态证据区没有背景动画。彩色校验按钮仍仅用于工作区的“开始校验”。布局在窄屏将双侧证据改为上下对照，并保留 44px 操作高度、可见焦点与减少动画偏好。

相关单元测试：`frontend/tests/publicEntry.test.mjs`（入口目标、认证安全回跳、三种访客状态、超时与迟到请求契约）。与 routing、sessionForms、userGuide 共 18 项窄单元一次通过，统一生产构建通过。

`frontend/e2e/publicEntry.spec.ts` 的 8 个有限 Mock 场景一次全部通过：401 公开首页与静态指南、慢探测超时及迟到响应、失败探测与认证页返回、提醒取消/Escape/焦点、登录目标及站外 returnTo 回退、注册切换目标且不自动导入、私密深链及失败时封闭、已登录/本地匿名旧根兼容。全部 API/跨源 API 被 Mock 拦截，未知请求和业务写入为零；仅允许指定的模拟认证 POST。没有调用真实模型、读取私人数据或访问封闭标注。

1440×1000 与 375×812 的公开首页和提醒共 4 张实际视口截图已核对，没有水平溢出，提醒操作完整可见。现有临时测试服务返回本次新构建，未改变 Host 白名单或重启服务。最终 CI 记录见[当前阶段状态](current-stage-status.md#2026-10-09-公开入口增量)，Mock 验收不替代服务端认证安全或模型质量评测。
