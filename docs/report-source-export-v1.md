# 文件往返与逐条来源导出 V1

状态：实现、本地集中验收及五项 CI 完成；本机安装以最终交付收据确认。用户已选择先配合 Word／Markdown 文件使用，完善导入、带出处的报告及资料导出。

## 作者需要解决的问题

现有 Markdown 报告包含引文、文稿名和行号，并在开头列出本次审查输入版本。但单条引文没有独立标明版本；当角色设定来自此前确认的材料时，报告顶部清单不足以说明这条证据究竟属于哪份旧文稿。

这次完善已有“下载审查报告”：每条正式问题证据独立展示来源名称、版本、行区间和原文核对状态。作者在外部编辑器阅读报告时，可以分清引用的具体版本，不会把旧报告的行号当成当前修订稿的位置。

## 审查报告

- 沿用现有已完成报告的授权下载接口和 Markdown 格式。
- 使用报告保存的来源，以及已有冻结原文核验规则；不通过当前同名文稿补齐旧证据。
- 来自既有确认特征的旧来源，仍按对应的历史来源核对，不能套用当前报告输入版本。
- 无法核验的历史摘录保留，并用普通中文说明限制；“已核对原文”只说明出处对应，不代表模型结论一定正确。
- 正式问题、反馈和既有开放问题保持原口径，不将待复核线索或物品历程混入正式问题。
- 新增的用户文案不用数据库编号、长摘要或内部异常名称代替来源说明。
- 行号对应 LoreGuard 解析后保存的原文，不代表 Word 页码、排版行号或修订后的新位置。

## 选择并导出本次资料

入口放在已完成报告的下载操作附近。作者展开本次输入清单，核对文件名、版本、资料身份、故事范围及待审稿／背景用途，再勾选要带走的文稿。默认不选，不自动收集当前整个项目或隐含的确认特征旧来源。

下载统一为 ZIP，即使只选一份。包内有可读的 `资料目录.md` 与各份 Markdown 正文。目录记录平台文稿名称、版本及用途；正文采用平台解析后保存的原文，不插入版本前言，以免改变原文行号。Word 中的排版、批注和修订痕迹需要使用原 Word 文件。

服务端核对所选材料确实属于该报告、旧正文完整且与其保存摘要一致。任一选中来源无法核对时，整次下载明确失败并保留选择；不能静默漏文件、猜版本或替换成当前新版。初始上限为每包 100 份、所选正文 UTF-8 总大小 20 MiB，超出时提示分批下载；不截断正文。

## 回到原工具修改

作者可以按原格式修改稿件，也可以使用改名或转换为其他受支持格式的修订稿。沿“修订并复检”入口手动选择要更新的文稿，核对“上传文件 → 平台文稿名及版本”后保存，再核对选入资料并手动发起复检。按[修订稿手动对应](explicit-revision-mapping-v1.md)，平台保留所选原文稿名称和版本链；不自动推断文件对应关系或拆并章归属。需要保留 Word 排版、批注时，仍应修改并上传原 Word 文件。

导出不会更新资料、撤销作者确认、自动发布或调用模型。旧报告保持原证据，新复检继续冻结当次输入；既有回流的幂等和失败恢复机制保留。此批不新增外部 API/MCP 插件或自动同步协议。

## 接口与来源边界

`GET /api/v1/analysis-runs/{run_id}/export.md` 继续返回正式审查报告；逐证据说明复用原文阅读器的授权与核验逻辑。只在单次请求中缓存问题、确认来源索引及已核原文，仍逐条核对行区间与引文。

`GET /api/v1/analysis-runs/{run_id}/source-materials.zip?document_id=...` 接收重复的 `document_id` 参数，必须明确选择本次输入，不能省略后自动导出全部。仅已完成且属于当前账户工作区的报告可下载。越权报告返回 404；选择为空或重复等请求错误返回 422；来源不可用或损坏返回 409；正文大小超限返回 413。

正文来自 `AnalysisRunInputRow`，版本与资料身份来自该次已保存的记录。旧报告确实没有保存的资料身份可写为“未保存”；已有但损坏的身份不能用当前资料身份代替。新增字段及来源说明不回写报告、文稿或作者确认。

## 集中验证计划

一次集中核对以下路径，再合并修复发现的问题，仅复查受到修改影响的部分：

1. 文稿更新后，旧报告导出仍引用旧版原文和版本。
2. 同名文稿及确认特征的历史来源能按各条证据区分，不能错误继承本次输入版本。
3. 来源缺失、权限不符或内容无法核对时不假称已核验；历史摘录与限制能被正常阅读。
4. 正式问题、线索、反馈及开放问题边界不变，下载不会创建分析或调用模型。
5. 资料 ZIP 只包含明确勾选的冻结正文和可读目录；正文及行号不被版本说明污染，来源不完整时不下载缺件包。
6. 勾选、下载失败、切换报告和会话状态沿现有账户隔离规则，不将旧报告选择或迟到下载用于另一个报告。

优先复用已留存的真实开发报告和独立 QA 副本。此批验证的是导出准确性，不是新模型成绩或独立封闭评测。完成后补充实际结果与交付版本。
