## 本轮实现

- 每个文档记录模型启用/配置情况、分块总数、逻辑调用/成功/失败/跳过数、无效记录、有效空记录响应与安全原因码，运行级汇总后持久化。
- 模式与新评测严格分母均采用结构化记录；警告文字变化不改变结果，预算耗尽、截断和部分非法记录不能标为完整成功。
- 空 `records` 是一次合法空抽取，不代表不存在剧情问题；缺少 `records` 则为协议错误。
- 页面展示真实计数和限制原因，旧运行缺失计数显示“未知”，不推断模型未使用或成功覆盖。
- 在主体、值、时间和原文证据都匹配的前提下，将模型额外携带的系词“是/为”对齐到既有基线谓词；不全局删字，不合并不同谓词或时间的事实。
- 连接诊断脚本复用生产 JSON 网关，输出仅包含安全状态、耗时与用量；网关拒绝重定向，不输出可能携带上游值的异常正文。
- 复杂评测保存结构化执行事实，历史报告只保留明确旧标记并标注未验证，不追认新协议成功。
