# 离线标注 V4：成长与表现的关系方向

日期：2026-11-02。范围是离线作答、仲裁、关系保存与评测记录，不修改网站模型或 Prompt，不代填真人答案。

## 本次问题

标注者需要表达的不是“这段成长与行为无关”，而是“成长所确立的变化与新稿行为相反，属于反向证据”。此前 G/X 只提供正向解释的明确程度；关联后，程序就把对应事件当作有解释，未知关系还可能在导出时回落到正向的 `bounded`。因此不能仅增加一个按钮而不改保存和校验。

新版区分“经历本身发生了什么”和“它与这次表现是什么关系”，不因为选中了成长材料就认定它替该行为提供合理解释。

## 关系按具体表现选择

- **能解释这次表现**：为对应事件提供解释，不能用被解释的事件支持正式冲突。
- **与这次表现相反**：保留为反向证据，不作为该事件的开脱理由；仍需核对基线、当前表现、人物／对象／情境、时间、材料和真人确认，不能自动定为 L3。
- **尚不能确定**：该关联保留待复核，不把未决关系当成确定反向证据。若整题结论依赖此关联，应保留疑点；若不靠这段成长就已能确认表现与设定一致，仍由真人判断整题，不额外强制改成线索。

同一段成长可能解释表现 A，却与表现 B 相反，所以方向按关联目标分别记录，不是给整张成长卡片设置全局正负。关系方向与依据明确程度不同；“与表现相反”不等于“解释不够明确”，也不等于“没有关系”。不相关材料仍可留空，不强制为每段原文建立关系。

同一事件有多个片段时，适用的解释或未决关系仍作用于整个事件，不能把该事件拆成多个片段绕过解释。P 仍属于未决材料，不能仅因选择反向就当作已确认的正式冲突依据。

新版仍为 18 题，仅按中文句号和分号（`。；;`）分片，原有换行和完整原文保留；选择为主，补充说明选填，不增加必填文字。

## 版本与保存

新手册为 `ooc-manual-v4-relations`，公开关系策略为 `directional-evidence-v1`，原单次明确冲突策略 `single-clear-event-v3` 不变。旧版没有关系方向字段时保留其原有正向解释语义和规范哈希；不把旧记录静默转换成新反向证据。

作答、草稿、本人锁定导入、仲裁与重新导出都应保留方向，未知方向不得默认回落为正向解释。关系变化后撤回正式冲突人工确认，需要本人重新核对。人工分歧比较按具体来源—表现及方向核对，不能把同一材料的相反判断当作一致。

人工标注和裁决保留完整关系；私有 gold 的辅助关系记录也保留来源角色、方向及其对应表现。正式报告现有必要 B/C 引用与网站原生 G 解释不能被伪造成反向模型判断。本轮不因此宣称网站已支持该能力或通过真实质量评测。

新包使用独立数据集与冻结绑定，保留原题顺序、文档、证据锚点和来源映射，不再次分片或改写原文。旧页面、旧结果和旧浏览器记录保留，新增关系不由软件替人默认或推断。

## 生成方式与验收范围

升级工具为 `scripts/upgrade_ooc_relation_round.py`，只接受两份明确指定的无答案 V3 作答页，不扫描真人结果、gold 或预测。输出目录必须是尚不存在的桌面 dev/doc 子目录，源页面与源冻结材料归档在 `source-v3/`，新材料在 `bundle/`；输出前校验公开绑定与来源，输出后做纯本地执行器预检，不发送 HTTP 或模型请求。

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/upgrade_ooc_relation_round.py `
  --reviewer-a <V3-A.html> --reviewer-b <V3-B.html> `
  --output-root <尚不存在的桌面dev或doc子目录>
```

后端相关 8 模块首批 175 项，166 通过、2 项新辅助 gold 构造错误、7 项合成 fixture 换行初始化错误。分别保留 Python tuple 类型与明确写入 LF 后，只补这 9 项，9/9 通过，没有重复已通过的 166 项。作答与仲裁非浏览器首批 21/21 通过；收口时仅定点检查未决明确度只读、非法组合拒绝和 P 文案相关 3 项，3/3 通过。未决明确度固定为 `ambiguous`，非法导入直接拒绝而不是改写。

浏览器只用另外虚构的材料集中验证保存、重新打开、逐目标混合方向、严格导出导入、仲裁与辅助关系。上述结构检查不代表真人盲测完成或真实模型质量通过，也不替代网站实际判定策略的后续适配。

集中合成管道验证 10 组浏览器场景，首轮 10/10 通过；另精选源码浏览器 4 项（旧作答页、旧仲裁、V3 仲裁、V4 混合关系仲裁），首轮 4/4 通过，没有重复其他已通过场景。两份合成 18 题导出与本人重新导入再导出均通过严格公开输入／作者配置绑定，正向与反向值原样保留；仲裁到 gold 的辅助关系也已核对。外部请求和浏览器异常为零，375px 关系选择与手册截图已目视。
