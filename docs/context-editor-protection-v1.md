# 资料身份编辑防丢稿 V1

本阶段保护的是“项目与文档 → 确认资料身份”中的手工字段，不是正文编辑器，也不是自动保存。

## 作者操作

- 系统读取成功后，以当时接受的资料身份作为独立基准。资料类型、发布状态、时间线、活动/篇章、版本标签、版本顺序、分支路径、互斥分支组和人工核对共九个字段中任一个变化，都会显示未保存提示。把字段改回原值则不再提示。
- 手工修改只在本页内存中。点击“保存草稿”或“保存并确认”才提交；不会保存到 sessionStorage、localStorage 或账户中的其他位置，也不能保证刷新、强制退出或浏览器崩溃后的恢复。
- 切换资料、离开本页、重新读取并采纳服务器最新身份、以及用 AI 建议替换已有手工字段时，未保存修改须先获得作者确认。取消后不切换资料、不发相应读取/识别请求，也不清空输入。
- 刷新/关闭页面会请求浏览器的原生离开提示。是否显示及提示内容受浏览器规则约束；不能以此承诺持久防丢稿。
- “重新读取”明确表示放弃本页修改并采纳服务器最新内容，不会自动合并两个版本。读取失败仍保留原输入和已经接受的基准；初次读取失败不可将资料列表的旧值冒充最新身份后保存。
- 保存失败保留输入。网络、服务器异常或无法核对的成功响应不能证明写入未发生，因此显示“保存结果待核对”，须读取最新状态核对，不能直接重复保存或识别。

## AI 与发布边界

AI 识别不是纯前端预览：该已有接口会保存一条**待确认修订**，然后把建议放进本页字段。开始识别时若已有手工修改，会明确提示其替换效果；作者仍须另行核对、保存并确认。AI 不会自动确认资料身份、不改写正文、不自动发布章节。本轮没有新增模型调用、修改提示词或改变审查判定。

既有“作者定稿并发布”仍是单独的人工决定，防丢稿功能不改变发布政策。异步读取、保存、识别、发布的回包在通知父级前检查项目、资料、组件实例及请求代次，离开后旧响应不能修改新页面。

## 上传与旧版本

同一项目导入文稿后，项目刷新不先清空资料并卸载编辑面板。未替换当前资料时，本页手工修改保留；当前资料变为非活动版本、被替换或不再出现在清单中时，旧文档 ID/名称/版本及本页字段仍保留供核对。

已成功读取且仍可访问的项目若刷新暂时失败，保留上次读取的页面、资料身份修改及原选中报告，并显示“项目资料刷新未完成”和“重新加载项目资料”。旧列表不被宣称为最新；初次尚未完成的读取、跨项目加载或权限失效不适用此保留。无运行项目的空运行标识按未选择运行处理；指定的非空运行 ID 仍须精确匹配，不会悄悄改为其他运行。

旧版本不允许保存身份、AI 识别或发布，更不会按相同文件名把旧字段绑定到新文稿。作者明确“放弃旧字段并选择活动资料”，或自行选择指定活动资料后，才读取新资料。没有活动资料时继续保留旧字段说明，不会凭空选择新版本。

## 导航与认证

站内导航在修改历史记录前检查当前离开保护。浏览器后退/前进的多个监听器共享一次决策；取消时回到原历史位置，编辑器不会因另一个监听器短暂卸载。

会建立新项目/样例并转移工作台的入口，在创建请求前先询问当前资料身份编辑器。创建请求期间若作者继续修改字段，原许可失效，最终转移前须重新确认；这不是跳过导入队列或其他编辑器的许可。创建后的最终导航被取消时不继续启动分析。

主动退出在退出请求前确认未保存身份字段；认证已失效时必须离开私有页面，不受未保存提示阻挡。旧回包同样失效。此功能不是账号隔离或加密机制，也不增加新的隐私存储。

## 验证

2026-10-03，本阶段已完成：

- 初批三个相关单元测试文件合计 42 项通过；集中修复后两个受影响文件 31 项通过，最后新增的已加载项目刷新守卫定点 1 项通过。去除重复执行后，本阶段相关的独立单元用例共 44 项。不是把每次执行数累加为测试规模。
- 最终 TypeScript 校验与 Vite 生产构建通过，包含同期帮助文案。
- 独立 Mock 浏览器作者流程共 10 个，全部闭环。主批 9 项通过，1 项校正文案断言；集中修复仅复测原 1/5/9，再对空运行标识导致的真实刷新失败定点复测原 9。未再运行整套浏览器测试或扩大功能矩阵。
- 真实浏览器 `beforeunload` 对话框的取消与确认均已观察；桌面与手机两个视口完成流程/视觉核对。不是仅检查源码中是否注册了事件，也不是宣称关闭后草稿仍可恢复。
- 单元与浏览器场景涵盖九字段改动、切资料取消、站内离开、真实浏览器刷新提示、后退/前进、重读与保存失败、AI 启动确认、同项目上传刷新/旧版本保留、旧读取回包，以及同 ID 畸形 `current` 拒收。只有成功读取过的项目可保留旧编辑框架，合法零文稿项目不以文稿数量推断是否已加载。认证失效的强制离开与旧回包失效已接入，但本批十个流程没有单独模拟带未保存身份字段的过期会话，也没有实际关闭浏览器来验证恢复。

浏览器 API 全部拦截，未访问真实数据库、私人文稿、人工封闭评测标签或模型接口。上述结果是前端合约与作者流程验证，不是 AI 判定质量指标；真实系统回归以统一 CI 为准。

统一交付核对已确认当前本地 8080 的首页与本次构建静态资源可访问（HTTP 200）。本阶段不需要重启服务或数据迁移，刷新页面即可加载新版；该静态检查不代表访问或验证了账户业务数据。
