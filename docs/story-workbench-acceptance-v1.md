当前状态（2026-11-07）：本阶段实现、一次集中体验和全部八次开发分析已结束，最终功能 `3f605f8` 的五项 CI 全部通过。下文保留设计／准备及分线实施记录，其中“待运行”等为当时安排；最终效果和未解决边界以[当前阶段结果](current-stage-status.md#最新阶段故事工作台与常用审查改进)为准。本机安装由最终交付收据另行确认。

日期：2026-11-07。阶段 0 准备，以 `dce965a` 为既有功能基线；本清单尚不是新布局或新语义能力的通过记录。页面方案见[布局与复用方案](story-workbench-layout-v1.md)，判断边界沿用[常用能力覆盖](core-capability-readiness.md)。

本阶段的作者任务是：进入自己的作品 → 导入或查阅资料 → 明确本次目标和依据 → 后台审查 → 核对问题及双方原文 → 反馈、外部修订、复检比较 → 自主发布。只有正文也能起步，不能要求先补完整百科。

## 阶段 0 判断与一次布局建议

现有账户、个人模型配置、导入、资料身份、版本、角色确认、原文阅读、任务恢复、报告、反馈导出、复检和发布均可复用。新增工作主要在导航、阅读与操作联动，不另建这些基础设施，也不扩展自动写作、状态库或第三方接入。

已查看既有 Updream 首页、即梦应用导航和马良故事工作台截图，仅用于理解布局诉求；不重新调查竞品，不把参考截图或账户信息放进仓库。与布局方案一致，建议如下：

1. **一眼分清所在层级。** 全局“我的作品／模型设置”和作品内“资料／角色／审查／报告”区分；作品名与返回入口常驻。避免全局栏、作品栏、目录栏同时展开挤压正文，辅助栏应可折叠。
2. **首页服务于继续工作。** 作品名、真实状态、明确下一步优先于装饰；欢迎背景和半透明只放入口，长文区采用安静、稳定的实色面。仅展示现有 API 已给出的事实，不从当前分页推造全局待办数。
3. **阅读状态跟随作品和版本。** 从目录进入正文、切换身份工具、点选问题再返回，应保留选定版本、搜索、页码／位置。切换作品或报告时清除不再属于当前任务的旧面板，迟到响应不能串入新任务。布局记忆不扩大正文／备注的既有暂存政策。
4. **报告先说对照什么，再说结论。** 目标稿／背景、资料身份和版本靠近结果；当前文稿阅读与“本次分析冻结原文”明确区分。报告须有当前选中问题和持续的冻结原文阅读区，双方依据可切换、反馈在近旁，不能只是原长列表加一个目录。右侧状态区不能把正文和双侧证据挤成窄条；低宽度优先原文与当前问题。资料工具采用抽屉／折叠即可，不再叠成长页表单。
5. **操作有连续性。** 反馈后能接着上传修订、复检和比较；发布仍是独立的作者决定。证据关闭、侧栏收起和浏览器返回恢复合理焦点，不用延后自动聚焦抢走正在输入的字段。
6. **窄屏改变组织而非缩小字。** 手机单列＋目录／辅助面板入口；正式问题、覆盖警告、两侧证据与下一步都可达。固定导航不得遮挡引用行和聚焦控件，状态除颜色外有文字，主操作触控目标约 44px，键盘可完成路径。

这些是基于已定稿布局的体验建议，不是对尚未稳定源码的审查结果。沿用现有设计系统，不新增第二套主题或页面状态存储。
