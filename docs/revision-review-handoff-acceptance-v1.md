## 固定范围

普通作者从已完成报告进入修订，保存后核对**本次返回的新文稿**与**明确选择的原目标**，再核对同一新版本的资料身份，最后返回原报告的复检准备。只准备，不提交付费分析。本批默认 0 模型、0 新分析，不重复上批上传幂等、跨格式与迁移整套验证。

真实旅程复用上一阶段的独立 QA 数据副本、真实习惯报告与已确认 `habit-draft.md` v2。集中执行时再建立一个新的 QA 工作副本，最多正常上传一份 v3，以真实呈现新版本身份待确认；不改原 QA 数据或生产库，不从收据拼造历史。v3 的具体输入及 SHA 在运行前冻结，不发送预期判断。

本次版本链须区分三个身份：旧报告冻结的是 v1；作者此次选中的替换目标是 v2；保存返回的是 v3。正文比较必须 v2→v3，旧报告原文仍 v1，不能为了方便改成 v1→v3 或自动换成最新版本。

## 一次集中验收

| 旅程/边界 | 本批证据 | 复用与限制 |
| --- | --- | --- |
| 保存→正文对比→资料身份→回原复检 | 新 QA 普通账户、真实 API 与受测前端；记录上传返回的 ID/版本、diff 两侧 ID/版本、身份请求目标与原 run | 最多 1 上传、必要人工身份确认；不点击“开始复检” |
| 尚未确认身份 | 上传后应明确指出准备条件不足；同一版本保存正确身份后刷新准备状态 | 不把上传成功等同身份确认，不绕过原准入门 |
| 未保存身份编辑与返回 | 在同一连续旅程检查离开保护；取消留在原编辑，明确放弃/保存后返回原 run | 不写入别的文稿；原确认特征与旧报告保持 |
| saved 版本不再 active、切项目/报告或迟到响应 | 必要的一个受控浏览器边界，核旧对比可读但身份/复检停止、不能换 latest 或串目标 | 后端权限和 CAS 沿既有专项，不重新全排列 |
| 截断但无 hunks | 受控浏览器/纯函数检查显示范围限制，不能宣称全文相同 | input_truncated 限定比较范围；output_truncated 限定展示，两者分别解释 |
| 准备后资料发生变化 | 浏览器只补不自动提交、发送当前 `expected_input_signature`、收到 `409 recheck_inputs_changed` 后重新核对的受控交互 | 实际项目锁/选材变化/拒绝后无 run 和 provider 由 engine 独立专项验证，不在浏览器重复整套；真实 QA 仍不提交分析 |

`inspect` 路由只是重新查看指定版本的入口，不是上传成功证明。刷新时可重新读取 v2/v3，但不能宣称恢复了原文件、上传收据或可重试操作。无成功收据时与真实上传后状态分别记录。

新增预期检查合同为 `material-impact.recheck.input_signature: string|null`，POST 可选 `expected_input_signature`（64 位十六进制）。它是本批新增防护；先前服务端去重签名并不等于客户端预期检查。旧无该字段调用兼容、同键不同 expected 不可冒充重放，以及真实选材竞态拒绝且不创建 run/provider，由后端 22 项专项承担；本次真实 QA 不提交分析来重复验证这些边界。

真实旅程采用桌面与 375px 的同一流程，留下受测产物截图；不另跑上批 31 后端或 7 浏览器。后端现有 diff/preview/身份 CAS 专项由接口方确认复用，本批只针对变化补验。集中发现一次反馈给原所有者，修复后只复查受影响项。
