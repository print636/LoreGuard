# 有界运行历史 V1

状态：后端与网页已实现，阶段集中验证及同一代码版本的五项 CI 均通过。日期：2026-10-02。

## 产品任务与边界

作者可在项目的运行历史中按状态筛选、逐页浏览，再打开一条运行查看冻结输入和结果。
列表不应为展示第一页而下载每次分析的全部输入清单、用量诊断和角色快照。
本期不新增分析，不更改报告、重试、复检、角色基线或正式问题的判断。

## 只读列表接口

`GET /api/v1/projects/{project_id}/run-catalog`

参数：

- `page`：默认 1，范围 1–100000。
- `page_size`：默认 20，范围 1–50。
- `status`：默认 `all`；仅接受 `all`、`queued`、`running`、`completed`、`failed`、`cancelled`。

响应：

```text
{ project_id, page, page_size, total, has_more,
  items: [{ id, project_id, status, created_at, started_at, completed_at,
            input_chars, prompt_tokens, completion_tokens, estimated_cost_usd,
            frozen_document_count, retried_from, batch_mode }] }
```

`total` 为当前状态筛选后的数量，`has_more` 采用同一口径。排序固定为
`created_at DESC, id DESC`，时间相同时由 ID 稳定排序。超出最后一页返回空 `items`，
仍保留实际总数。Offset 分页不是跨请求快照：浏览期间新增运行会改变后续页位置。
历史脏数据中的非标准状态在 `all` 列表仍占一条记录，返回 `status=unknown` 并显示
“状态未知”，不回显原值；`unknown` 不作为筛选参数，也不会将该运行错误归入正常终态。

`frozen_document_count` 仅统计保存的冻结输入行数，不证明快照完整、哈希有效、
角色基线已就绪或审查质量达标。输入版本、Hash 与覆盖诊断仍在选中运行的详情查看。
`prompt_tokens` 与 `completion_tokens` 仅是已保存的计数；列表不把零计数解释为模型未参与，
也不把中断运行的局部计数宣称为完整总用量。完整用量边界以运行详情为准。
`estimated_cost_usd` 在未配置价格时为 `null`，不是 Provider 账单或实时计费。
`retried_from` 只返回同项目的有效源运行 ID，损坏或跨项目的历史谱系不泄露其他项目 ID。

## 查询与隔离

接口先验证当前工作区拥有该项目；未知项目与其他工作区项目统一返回 404。
参数错误返回 422。该路径的成功和错误响应均采用 `Cache-Control: no-store`。
读取只选择有界运行页的标量元数据，以及这一页的输入行数聚合；不会加载正文、
文档名称、Provider identity、密钥、错误原文、batch coverage 或 diagnostic JSON。
不调用 `serialize_run`、模型或分析调度，也不写入业务数据。

复用已有 `ix_analysis_runs_project_created_id` 索引，不新增 schema 或迁移。
状态筛选仍需在项目运行集合内计数；本阶段不宣称百万级数据性能或无成本计数。

## 兼容与迁移限制

原 `GET /api/v1/projects/{project_id}/analysis-runs` 的全量数组契约保留。
网页本期只将“运行历史展示”迁移至新列表；现有引导审查准备状态、角色基线相关
消费者仍沿用旧数据来源，不得把列表第一页误当作全项目运行集合。
当前选中运行即使不在历史页中，也应继续按 ID 加载详情；翻页或筛选不能切换报告，
不能开始、取消、重试或复检分析。

这是一条有界列表路径，不表示整个工作台已经完全消除全量运行元数据依赖。

## 网页操作与状态

运行审计页的 `RunHistoryPanel` 挂载时按需读取目录，每页 20 条。状态筛选与页码写入
`history_status`、`history_page` URL 参数，浏览器后退可恢复列表条件；这些参数不改变
当前运行路径，翻页、筛选或刷新列表都不会替作者选择另一份报告。
列表外的当前选中运行仍可在详情中查看；点击具体条目的查看入口才按 ID 恢复该运行。

列表分别处理首次加载、失败后重试、无运行、筛选无匹配和超出最后一页；超页时可以
返回实际最后一页。请求使用取消与代次核对，旧页、旧筛选或旧项目的迟到响应不会覆盖
当前列表。未知状态显示“状态未知”和查看详情入口，不提供错误的正常状态筛选。

列中仅展示保存的输入行数与“已记录 Token”等摘要，不展开全部文稿版本，不据此宣称
完整用量或模型参与；精确冻结版本、诊断和用量边界通过运行详情核对。沿用星轨书斋
视觉令牌，列表控件具有文字标签、键盘焦点及触控尺寸。

所有数据为独立临时 SQLite 数据库中的合成元数据，不使用真实用户数据库、
人工标注材料或模型请求。该验证不构成 PostgreSQL 大规模性能或角色 OOC 质量成绩。
