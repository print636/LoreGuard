# 离线标注 V3：原文片段与单次明确冲突

日期：2026-11-01。范围是离线作答、仲裁、公开评测契约与发放工具；不是重做网站、扩大题量或重新训练模型。

## 真实故障

原 18 题每份新稿的三行正文分别围绕三个不同人物／比较轴。每题指定人物的表现集中在一个物理行，该行内部可能已经叙述多次独立事件；标注工具却仅允许一行对应一条当前证据和一个事件组，同时要求至少两条当前证据、两个事件组。

所以，标题与其他角色的行为不能合法充作第二条证据；部分真实叙述无法通过原正式冲突格式校验。A/B 材料一致，指定基线可选，不是旧页面或标注者操作错误。此前合成浏览器用例把两次行为预先放到两行，遗漏了这种实际材料结构。

本次诊断未读取私人答案、gold 或模型预测，没有为题目预标注结论。真实材料只用于核对公开输入的组织与可表达性，不用于调整模型 Prompt 或生成参考答案。

## 作者确认的新判定规则

用户明确批准：单次已经发生、明确违反同一设定、人物／对象／适用情境一致，且所需资料完整、相关解释已核对的表现，也可支持正式冲突。关键事实、适用范围或解释仍有歧义时保留为待复核线索。

多次表现可以增强证据，不再是正式冲突的硬门槛，也不能机械换算成接近 100% 的概率。内向者偶尔主动交谈等情境性表现不因出现一次或多次就自动构成设定冲突。

新版 L3 需要真人主动完成语义核对确认，不预选、不由软件替人判断。证据、结论、事件分组、解释或材料充分程度改变后，需要重新核对。普通作答仍主要使用选择题，补充文字选填。

解释按其指向的事件核对，不因某一个事件有成长、伪装或可能解释就否决全部其他事件。仍未明确指向的可能解释不能被当作无关信息忽略。被解释或尚待解释的事件不用于支持正式冲突，原始标注和人工裁决保留完整背景。

## 修复证据粒度，不代替人划分事件

新包对所有公开材料使用同一套不依赖答案、人物或难度的标点分片规则，只新增分隔换行，不增加或改写原文字符。保留原始文档、行与字符区间到新片段的映射，原包另行保存。分片文档使用新 UUID、路径及初始版本 1，满足真实执行器新建项目的导入合同；不是在新项目里伪称已经更新到版本 2。选择题仍为原来的 18 题、6 个故事组，不扩大任务量。

片段是可引用的原文单位，不是模型判定好的事件。同一事件的多个片段应由标注者归到同一组；多段复述不构成多次发生。统一标点分片不等于已经完整支持任意无标点多事件文本；无法真实表达时应保留不确定性并联系负责人，而不是硬凑事件或错选其他角色。

## 版本与旧结果

新版手册为 `ooc-manual-v3-event`，公开评测策略为 `single-clear-event-v3`。新建独立数据集、文档快照与冻结值，不静默重解释 V1/V2 的规则或规范哈希。

新作答页不自动继承旧结论、依据分组、解释、正式冲突确认或独立完成声明。旧文件、旧浏览器草稿及旧锁定结果不删除、不覆盖；旧备注可在本人旧页查看，新版需按新材料粒度和新规则重新核对。旧结果不与新批次混算，也不把旧“有疑点”自动改为“存在冲突”。

仲裁和私有 gold 需要匹配同一公开策略。封闭预测投影只能根据公开策略选择格式门槛，不能读取 gold 来决定是否接受预测，也不能把网站的待复核线索伪造成正式问题。

## 与网站判断及模型质量的边界

本轮不修改 `app/` 的角色审查逻辑或模型 Prompt，也不调用真实模型。网站现有规则与新版人工判定仍需单独做产品策略适配与真实评测；不能据此宣称网站已经支持所有单次明确冲突，或已经通过新版人工封闭测试。新版人工答案会用于暴露这类差距，而不是为迁就旧实现把清楚的冲突降成线索。

旧阶段的测试成绩和未完成的完整浏览器 CI 保留原记录，不换算为本轮成绩。本轮验收仅使用隔离合成内容验证相同材料结构、版本绑定和离线操作，不用真实题目预填答案。

## 生成与留档

工具为 `scripts/repair_ooc_annotation_round.py`。必须输入原 18 题选择版 A/B 页面与尚不存在的输出目录；只读取这两份指定的无答案文件，不寻找真人结果、gold 或预测，不覆盖源文件。命令如下：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/repair_ooc_annotation_round.py `
  --reviewer-a <原18题选择版A.html> --reviewer-b <原18题选择版B.html> `
  --output-root <桌面dev或doc下尚不存在的目录>
```

本机新包为 `artifacts/annotation-event-v3/`，包含新冻结 `bundle/`、原页面原字节及原冻结 `source-18/`、两份新作答页、来源位置清单和批次说明。旧版位置的同名文件完成替换后，不得把新版再次当作旧输入运行工具。

实际公开新包已唯一一次生成，内置本地 `load_public_bundle` 预检通过，没有网络或模型调用。A/B 同题、本人身份保持、18 题／6 组／六维度各 3 题、24 份新文档 UUID／版本 1、所有片段与原文字符区间对应，以及不自动迁移答案均核对通过。
