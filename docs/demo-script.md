# 两分钟演示脚本

**0:00–0:20** 打开首页，说明“证据先于判断”，创建《潮汐之门》原创样例项目。

**0:20–0:40** 同时上传 `world.md` 与 `chapter-01.md`，展示设定和人工注入矛盾。

**0:40–1:05** 启动分析，指出 SSE 依次显示解析、检索、规则检查和报告生成；强调主流程无 API Key 也可复现。

**1:05–1:35** 展示五类问题及两侧原文行号，重点讲角色在中午获知口令，却在上午提前使用的知识越权问题。

**1:35–1:50** 把一个问题标记为误报，把另一个标记为已解决，说明反馈将进入后续评测集。

**1:50–2:00** 打开复杂原创验收报告，说明 14 例多文档场景覆盖五类正例和困难反例，当前无模型固定基线 TP 10、FP 0、FN 0；同时明确这是开发者可见回归，不是生产准确率，真实模型固定场景 Precision 仍约 0.556。
