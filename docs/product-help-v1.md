# 产品内使用指南 V1

状态：已实现，阶段集中验证通过。日期：2026-10-02。

## 用户任务

第一次使用 LoreGuard 的作者，不应先阅读开发者 README 才能理解资料身份、审查顺序和报告边界。
本阶段将既有流程编成随时可打开的简体中文使用指南，不增加剧情判断能力或另一套动态任务清单。

依据是 [产品基础建设规格](product-foundation-v1.md) P1 的“更完整的新手任务清单和上下文帮助”。
现有校验页已经具备状态驱动的三阶段引导，本期补充通俗解释，不复制其状态判定。

## 内容与入口

内容集中存放于 `frontend/src/features/help/userGuideContent.ts`，以纯文本、只读数组导出。
六个主题按“最短操作 → 必要概念 → 边界与恢复”组织：

| 主题 | 解决的问题 |
| --- | --- |
| 第一次使用 | 原创样例、只有正文、已有设定与历史三种起步路径 |
| 资料身份与发布 | 类型、确认、参考材料、故事范围与作者手动发布 |
| 角色基线与 OOC | 候选与已确认特征、比较轴、独立生效与撤销 |
| 选择章节并校验 | 待审章节、敏感度、模型配置、按需可视化、重试输入 |
| 阅读报告与原文 | 正式问题、角色审查线索、未验证提案、冻结原文、反馈与导出 |
| 覆盖范围与异常 | 任务完成与实际覆盖的区别、零问题含义、降级与恢复 |

项目中心、文稿校验和报告提供入口，在当前页面打开只读面板并选择对应主题。
不创建新的帮助路由，不为阅读说明卸载工作台；关闭后回到原触发入口。
沿用星轨书斋的排版与颜色令牌；长内容优先易读，不抢占“开始校验”的彩色主操作样式。

## 不改变的产品规则

- 没有世界观的正文可以自检，但其他草稿不会自动成为正式背景。
- 作者确认资料身份，不等于系统证明文稿事实正确；AI 建议不会自动成为确认结果。
- 新稿由作者主动定稿发布。没有报告、报告部分覆盖或仍有问题时，仍可在警示后发布；审查完成不自动发布。
- 已确认角色特征独立生效；来源文档归档或改为参考资料，不会自动撤销特征。
- 合理推断可以依上下文证据成立，指南不宣称只支持机械同字匹配；亦不宣称所有角色维度已达到生产质量。
- 正式报告问题仍需作者核对。待复核线索与未验证提案分别展示，不进入正式问题计数、问题反馈和导出。
- 报告原文只来自该次冻结来源，不能用当前新版替换；仅有摘录时明确阅读边界。
- 完成、连接正常、完整执行覆盖与判断准确是不同概念；零问题不是作品无误保证。

## 技术与隐私边界

阅读指南及切换主题不调用 API、Provider 或分析接口，不读取数据库，也不修改项目、文稿、
资料上下文、角色特征、反馈、发布状态或模型配置。不保存阅读进度、正文、密钥或业务资料。
帮助中的流程说明不直接代替用户执行操作；连接测试、发布、反馈等仍在原页面由用户主动发起。

不接触人工封闭评测题、私人答案或真实标注提交，也不复用仓外教学故事。
等待真人标注的 OOC 质量阶段继续暂停。本阶段不能被宣称为 OOC 准确率或模型能力改进。

## 阶段验收

本地集中验证覆盖下列行为：

1. 各入口与六主题可达，按钮名及流程与当前产品一致。
2. 仅打开、切换和关闭指南不会新增请求、写入或模型调用。
3. 工作台输入、已选新稿、报告筛选、未提交备注和审阅位置保持不变。
4. Escape、明确关闭入口、焦点管理和关闭后恢复焦点可用。
5. 桌面与 360px 移动端无横向溢出，长文、目录和键盘阅读可用。

非目标：动态新手任务追踪、已读状态持久化、产品规则调整、新 AI 功能、新模型评测、团队协作或新的业务接口。

### 集中验证记录

- 全部前端单元测试 200 项通过，含新增 3 项指南内容合同测试；最终 TypeScript 与生产构建通过。
- 浏览器第一轮集中运行新增指南 5 项及既有证据阅读、待复核线索 14 项：18 项通过，
  1 项发现原生对话框的键盘首尾焦点循环不符合显式边界。修复后仅复测该项及报告说明
  文案调整影响项，2 项均通过；最终覆盖 19 个独立场景，未反复运行整站测试。
- Mock API 全量拦截业务请求；指南操作前后 URL 与请求数不变，无业务写入或模型调用。
  核对校验台未提交正文、文本设置和报告筛选、选中问题、未提交备注不丢失。
- 1440、375、360 像素截图通过人工视觉检查；720×500 CSS 视口与 2×像素比模拟
  1440×1000 物理像素下的 200% 等效重排，不声称已驱动浏览器原生缩放设置。
  目录、正文末端和常驻关闭入口可达，无页级横向溢出；正文实测 16px、400 字重。
- 一次模拟新人阅读修正了报告版本定位说明：完整输入清单到“运行审计”核对，单条
  引用通过“查看分析时原文”查看冻结版本。没有新增业务规则或模型质量结论。

上述结果是产品交互验收，不代替真实人工封闭评测。

## 本机体验

刷新 <http://127.0.0.1:8080>。项目中心和文稿校验台点击“使用指南”；报告页点击
“阅读报告帮助”或“理解覆盖范围”。可按目录查阅，点击“查看目录”返回目录，按
Escape 或“关闭使用指南”回到原入口。原页面保持挂载，无需离开正在填写的工作。
