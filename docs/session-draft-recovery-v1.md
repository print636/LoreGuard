# 当前标签页未提交草稿恢复 V1

## 范围与使用

- 仅账户模式（`AUTH_MODE=required` / 身份 `mode=required`）启用；本地匿名体验明确提示不暂存，请先复制备份。
- 快速自然文本实验台：正文和可选设定的真实改动即时写入当前标签页 `sessionStorage`，同时保存文本模式、文档身份与故事作用域。默认原创样例正文/设定不自动写入缓存。
- 快捷入口会创建独立项目，缓存的项目槽位固定为 `__quick_text__`，不会恢复到某个已有项目的服务端文档中。此版本不缓存文件对象、新项目标题、角色编辑表单、模型设置或叙事上下文表单。
- 正式问题的未提交备注绑定账户、工作区、项目、运行及问题 ID；只有服务端已验证可访问的运行和已加载的问题才允许恢复。待复核线索没有正式问题反馈入口。
- 刷新或会话过期后，重新验证同一账户与工作区才自动恢复，页面说明“仅本标签页暂存，尚未保存到项目／提交反馈”；不自动启动分析、提交文档或反馈。
- 不同账户登录不会展示或自动删除之前账户的草稿；只有原账户可通过产品恢复自己的命名空间。
- 主动退出先撤销写入租约，再清理当前账户／工作区的 LoreGuard 缓存，避免已发出的请求或组件卸载再写回。其他账户缓存及其他站点用途的存储不受影响。
- 快捷文本的所有相关文本上传成功后清除对应缓存；后续启动分析失败不把已导入文本当成未提交稿。上传失败保留草稿。保存过程中继续输入时，只清除请求提交的版本，不清除后来改动。
- 备注提交成功后只清该问题的未提交内容，其他问题的备注保留；提交失败不清。丢弃按钮需要确认，仅清本地缓存和未提交输入，不修改已保存文档或已提交反馈。

## 隐私边界

这是作者选择的防丢稿折中，不是安全加密库。正文和备注以未加密 JSON 暂存于本机浏览器的当前标签页；同源脚本、可访问该浏览器的其他人和开发者工具可能读取。账户命名空间和登录后校验是应用恢复边界，不是加密隔离。不得存入 API Key、密码、模型设置、提示词或诊断信息，也不输出正文到客户端日志。

不使用 `localStorage`，不发送缓存内容到服务器；不添加新保留期限或云端自动保存策略。`sessionStorage` 通常限于标签页生命周期，但浏览器会话恢复、复制标签页等机制可能保留或复制它，不能承诺关闭页面后永久销毁。共享设备上应主动退出并检查清理结果。

## 异常与限制

- 单份包上限为估算 2 MiB（JSON 字符长度 × 2），用于控制同步写入体积；不限制编辑器正常输入或文档提交。
- 达到上限或浏览器配额时，保留当前页面输入及最后一次成功暂存版本；提示最新改动未暂存、先复制备份，刷新只能恢复最后一次成功版本。不会显示“已保存”掩盖失败。
- 浏览器禁用存储、访问失败或 JSON 损坏时不崩溃、不恢复未经验证的内容；可继续编辑、复制备份或丢弃损坏缓存。
- 主动退出时清理失败会在登录页明确警示。在当前页面生命周期内拒绝恢复该旧缓存；跨整页刷新无法代替浏览器执行一项被它拒绝的删除，应自行清除该站点数据。
- 本轮没有把既有服务器文档自动转换为本地未提交稿，也没有宣称离线云端编辑、跨设备同步、端到端加密或所有表单通用恢复。
