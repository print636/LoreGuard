# 离线标注：18 题选择版

日期：2026-10-23。按两位标注者不愿反复打字、阅读与作答负担较重的反馈，在原易读版之后缩减题量，并改为选择为主。本轮只涉及离线作答工具和配套说明，不开发网站、修改模型或代填真人答案。

## 标注者看到的变化

- 每人由 36 题改为 18 题；A、B 仍独立完成同一套题，不是每人做一半。
- “观察到了什么”和“判断的关键理由”改成通用多选。所有题使用相同选项，不预选，不随题目或结论推荐答案。
- 原必填的文字说明改成“补充说明（选填）”。没有合适选项时可以直接选择对应出口，不强制填写“其他”。
- 原文依据、结论、材料充分程度、把握程度和独立作答声明仍由本人选择。“这是哪一次事情”改为下拉菜单，不必打字命名。
- 正常完成全套可以零打字；必要的证据来源、两次独立事件和解释对应条件没有放宽。格式检查通过不代表剧情判断正确。
- 结果中的说明明确标为“按你的选择整理（不是 AI 给答案）”，机械记录本人选择；自愿补充的文字另列。重复导入不会反复拼接同一段说明。

教学手册也同步改为 18 题、选择式流程；只需先看三步，疑难规则按需展开。新增教学例子另行虚构，不来自正式题目。

## 减题不是沿用旧成绩

新批次为 6 个完整故事组、18 题，六个检查维度各 3 题。工具只按原公开顺序和维度元数据选取首个满足平衡条件的完整故事组组合，不读取答案、模型预测或根据猜测难度挑题。原文、案例、故事组、文档与证据身份保持原样。

新建独立 dataset 与公开输入、作者配置和执行冻结值，手册标识为 `ooc-manual-v2-choice`，批次为 `ooc-choice-short-round-v2`。原 36 题 gold、预测、分母与成绩不能直接用于本批次。未来若需计算结果，应先为此批次完成人工独立标注、分歧处理和锁定，再使用相同冻结材料执行预测与评分。

18 题来自 6 个故事组，不是 18 个相互独立故事。它只支持缩小范围的首轮验证，不代表全部 OOC 场景或生产准确率；未选入的题也不算已完成。

## 交付与旧进度

桌面 `doc/LoreGuard-封闭评测/` 的两份同名作答页、零基础 HTML 手册和 Markdown 手册已原位更新。旧四文件先逐字节备份到新建的 `原36题备份-选择版升级/`，核验后才替换；更早的易读版备份不覆盖。

浏览器如果仍能访问原本人旧草稿，新页提供明确的恢复入口，须本人确认；只恢复保留的 18 题，不迁移独立完成声明，不删除或改写原 36 题缓存。绑定同时核对原身份、冻结值、题目顺序和保留题快照；不匹配就拒绝恢复，原 36 题锁定结果也不冒充本批次结果。

本地文件的存储规则由浏览器决定，跨文件路径、设备、用户配置或无痕窗口不能保证恢复。已经开始填写者应先保住原文件和原浏览器进度；页面不能读到时联系负责人，不要求重新做题来覆盖旧结果。

本机完整生成包位于 `artifacts/annotation-choice-v2/`：

- `bundle/`：本批次原文、公开输入、作者配置和冻结信息。
- `round-manifest.json`：选取规则、数量、来源绑定和保留题映射，不含人工答案。
- `source-36/`：原 36 题页面原字节和可校验的原冻结材料。
- 两份新作答页、配套手册和批次说明。标注者只需作答页和 HTML 手册，不必阅读内部清单。

## 可复现生成

下列命令必须指向原 36 题输入和一个不存在的新输出目录；不能将当前已更新的 18 题当作原 36 题再次缩减。生成器拒绝覆盖，不自动部署到原位置。

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/prepare_ooc_annotation_round.py `
  --reviewer-a <原36题A文件> --reviewer-b <原36题B文件> `
  --output-root <桌面dev或doc下尚不存在的输出目录>

.\.venv\Scripts\python.exe -X utf8 scripts/render_annotation_reader_guide.py `
  --output <输出目录>/人工标注手册-零基础完整版.html
```

生成器只读取明确指定的两份无答案作答页，不搜索真人结果、gold 或预测。先校验两页公开材料一致及原文 SHA，再创建新冻结包；核对源文件未变后结束。配套 Markdown 手册来自 [annotation-reader-guide.md](annotation-reader-guide.md)。不要用旧版 `refresh_ooc_annotation_handouts.py` 将不同批次伪装成单纯的界面重发。
