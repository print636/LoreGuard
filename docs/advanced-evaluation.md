# 复杂故事回归场景

`data/advanced/` 是 LoreGuard 原创的多文档场景，用于检验模型增强抽取是否能跨段落、跨章节保持实体和状态一致。

它刻意避免“发色写错”这一类显眼矛盾，包含：

- 两份带有上下文掩护的同刻异地记录。
- 禁魔区域内发动能力的规则冲突。
- 唯一物品未交接却被使用。
- 角色在正式获知机密前说出坐标。
- 身体状态与后续动作的语义冲突。

`expected.json` 仅用于验收，不得放入抽取 Prompt，也不得作为运行时输入。真实验收需分别报告：抽取是否正确、检查器是否命中、证据行是否正确、是否产生额外误报。不能只报告“发现了几个问题”。
