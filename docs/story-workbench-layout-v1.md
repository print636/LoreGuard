# 故事工作台：阶段一布局与复用方案

本方案依据 2026-11-07 产品交接和现有 `dce965a` 实现。范围是现有作者流程的组织和呈现，不新增版本影响分析、状态库、外部接入或模型调用层。所有按钮连接现有操作；统计只来自已取得的真实项目与运行。

## 视觉方向

沿用 `design-system/loreguard/MASTER.md` 的星轨书斋。Updream 只参考入口的空间层次；即梦只参考全局导航与创作区的分层；马良只参考以作品目录、正文和侧栏组织工作。参考截图保留在本机资料目录，不进入仓库。

核心色：深靛 `#0D0A1E`、书桌 `#1D1739`、纸面文字 `#F4F0FF`、薰衣草 `#B7A2FF`、青色 `#8BE9F0`、提醒杏色 `#FFBD82`。使用既有语义变量，不建立第二套 token。界面为 Noto Sans SC / 微软雅黑，欢迎短标题可用既有中文衬线；原文和长报告保持无衬线、足够行距与安静背景。彩色主强调保留给“开始校验”。

技能检索的通用浅色营销页、推荐语轮播和英文书籍字体不适合本项目，未采用。采用其键盘顺序、可见焦点和固定导航不能遮挡内容的约束。设计重点由装饰转为作品、阅读位置、资料身份和可操作的审查结果。

## 三处关键布局

### 首页与作品入口

公开首页以一处欢迎空间说明用途，直接提供浏览工作区、导入与使用指南。登录后显示真实作品目录，不展示伪造的最近活动、待办或全局统计。保留现有搜索、排序、分页与逐项下一步判断。

```text
┌ 全局：LoreGuard / 我的作品 / 模型与密钥 / 账户 ┐
│ 开始一个故事                  导入文稿 / 新建 │
│ 正文即可开始，不要求先建百科                  │
├ 我的作品              搜索 / 排序 ──────────┤
│ 作品名 / 说明 / 实际文档数 / 运行状态 / 继续  │
│ 作品名 / 说明 / 实际文档数 / 运行状态 / 继续  │
└ 分页 / 加载与失败恢复 ──────────────────────┘
```

### 作品与阅读工作台

当前选定作品的目录和全文提前到首屏，不再先经过一长页项目创建、上传与资料身份表单。作品内导航明确分为资料、角色、审查与结果；全局返回及账户操作单独放置。导入与资料身份仍在同页可达，保留未保存保护和全部既有功能。

```text
┌ 返回作品 / 当前作品名      导入文稿 / 准备审查 ┐
├ 作品导航 ┬ 章节与材料目录 ┬ 全文阅读 ─────────┤
│ 资料     │ 搜索与筛选     │ 文稿名 / 版本/身份 │
│ 角色     │ 正文/设定/参考 │ 正文、行号与搜索   │
│ 审查     │ 历史版本       │ 翻页 / 比较版本    │
│ 报告     ├───────────────┴───────────────────┤
│ 历史     │ 导入和资料身份工具，可明确展开      │
└──────────┴───────────────────────────────────┘
```

目录/阅读复用 `DocumentLibrary` 的已选版本、搜索及分页状态。桌面并排，小屏选择原文后可返回目录；切换工具不销毁阅读组件，不清空作者输入。不存在完整稿时显示真实空态，不生成正文或占位作品。

### 报告与处理

报告用真实问题目录选择当前问题，以问题说明和嵌入式冻结原文为主阅读面；作者可切换双方依据，保留各自阅读页和位置，原弹窗仍是辅助入口。覆盖、用量及继续处理在邻近区域。正式问题、待复核、待澄清、适用范围说明保持各自类别和计数，不相加冒充错误总数。沿用现有完整证据阅读器及其版本/来源信息。

```text
┌ 当前作品 / 本次报告       导出 / 修订复检 ────┐
├ 作品导航 ┬ 报告与问题阅读 ──────┬ 本次审查 ───┤
│          │ 范围与覆盖限制       │ 状态 / 用量  │
│ 问题目录 │ 正式问题/待复核      │ 实际输入范围 │
│ 分类定位 │ 双侧摘录与原文入口   │ 运行恢复     │
│          │ 反馈 / 备注 / 复检   │ 历史入口     │
└──────────┴─────────────────────┴──────────────┘
```

问题定位保留其他问题及阅读器的现有状态，完整原文关闭后返回触发位置。平板收拢辅助区域；手机采用单列、可展开目录和明确返回，不挤出永久三列。覆盖不足或无报告的发布沿原警示与显式确认，不因新布局改变作者政策。

## 路由和实现复用

| 功能 | 路由/现有组件 | 现有数据或操作 |
|---|---|---|
| 公开入口 | `/`，`PublicHome`、`LoginReminder`、`GuestWorkspace` | 既有会话确认；游客空工作区与登录返回路径 |
| 作品目录 | `/app`，`ProjectCenter` | `/api/v1/project-catalog` 的真实条目、分页和 latest_run；既有创建/导入 |
| 作品资料 | `/app/projects/:id/documents`，`App`、`DocumentLibrary` | 文档列表、现有 document preview；历史版本与原文搜索 |
| 资料身份/导入 | `NarrativeContextWorkbench`、`ImportQueuePanel` | 既有上传、替换、资料身份保存与未保存离开保护 |
| 新审查与进度 | `/app/projects/:id/check`、`GuidedReviewLaunch`、运行视图 | 目标与背景选择、账户模型设置、主动深审、原有任务恢复/取消/重试 |
| 角色资料 | `/app/projects/:id/characters`、`CharacterWorkspace` | 作者确认/撤销规则与全部现有授权保持 |
| 报告/证据 | 原 run report 路由、`App`、`EvidenceReader` | issues/review-clues/diagnostics、冻结 evidence preview、反馈与导出 |
| 复检/发布 | 原 revise/compare 路由、`RevisionReview` | 上传修订、显式复检、比较、手动发布及既有警示 |
| 全局设置 | `/app/settings/model`、`/app/settings/account` | 既有账户隔离、密钥遮罩、保存和探测 |

不为视觉改造新增全局聚合 API。保留原深链接与旧路由兼容，改呈现文字不改业务枚举。原文仍由既有授权接口读取；新布局不持久化第二份正文。

## 工时与验证

初估前端含体验验证为 32–44 工时；按团队去重后，前端设计、实现、组件验证与构建为 **27–37 工时**。最终集中浏览器验收和截图归作者验收席，统一计入其 10–16 工时，不再两线重复。以上是工程范围估计，不是任务运行倒计时；不以此增加后续阶段。

集中验证围绕已有普通流程：游客与真实目录、选中文档与原文、资料工具切换保留输入和阅读状态、问题定位/reader 返回、导出与修订入口、窄屏导航和键盘焦点。前端席补充阅读位置与双方原文的交互用例，由作者验收席在唯一集中浏览器窗口运行并保留桌面及 375px 实际截图；前端席交付一次受测生产构建。截图留本地 artifacts。无真实模型调用；完整模型验收由既定作者席统一调度。
