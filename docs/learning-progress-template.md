## 事实边界检查

每次讲到项目能力时，从[项目事实清单](project-facts.md)核对：

- 我说的是 `已实现`、`实验原型/默认关闭`，还是 `未来计划`？
- 我引用的数字是否同时带上数据集范围和失败门槛？
- 我是否把 Mock、合成注入或开发者可见回归误说成真实用户效果？
- 我是否误称已经实现多智能体、原生 function calling、生产高并发或长篇商业剧情能力？
