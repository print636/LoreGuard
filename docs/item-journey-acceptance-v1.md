物理持有/保管不等于法律所有权。观察到持有、实际使用、明确交接、持续保管须分别表达；不会因最新上传、章节序号或裸钟点排序就确立最后状态。别称不自动合并。模型抽取的已知缺口和旧报告的 partial 不因查询展示而消失。

## 唯一集中验收清单

1. **选择范围可理解。** 从已有报告进入物品去向，明确当前报告与版本；选择另一报告后不残留上一份的物品、结论或原文。不跨项目/账户借数据。
2. **铜钥匙真实链可用。** 显示仓管 → 许岩 → 陈蔚的有源交接及取用/收回，事件、人物、物品和原文时点对应；同一次操作产生多条记录不冒充多次独立交接。最后有据状态来自链与时间证据，不是列表最后一项。
3. **星钥未知保留。** 不把“没找到交接”改写为“没有交接”，不以观察覆盖明确持续约束；未决原因、未覆盖范围和报告 partial 保持可见。无记录与无问题都不等于事实不存在。
4. **每个事件均可读原文。** 通过 record 入口读取冻结文档、版本及完整行，包含限定、否定和上下文；零正式问题的铜钥匙同样可用。若现有资料后来更新，应读原冻结版本，并沿阶段2说明资料变化；不为验收改写真实用户资料。
5. **作者连续操作。** 桌面完成报告 → 物品 → 交接事件 → 冻结原文 → 返回；窄屏复用同一旅程，选择与阅读位置合理保留，无横向溢出或被顶栏遮挡的操作。只保存一组关键页截图，不逐页重复全站检查。
6. **无付费副作用。** 查询、切换、展开原文和刷新只读，不创建 AnalysisRun、不调模型、不改旧记录/报告/反馈/确认。加载失败与空结果分别显示，不沿用上一次成功结论。

后端专项负责状态类型、来源绑定、时间不可比、重复/分支、权限等必要组合；前端负责相关 unit/model、类型检查及生产构建。集中窗口审查本批差异与关键集成，复用这些证据，不在浏览器再全排列。实质问题一次汇总交原负责人，只补受影响项。
