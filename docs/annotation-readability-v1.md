# 离线标注材料易读版

日期：2026-10-23。目标是让第一次接触 LoreGuard 的真人能直接开始阅读和填写，不必先学习评测系统的内部结构。

## 发给标注者的文件

- A 使用 `reviewer-a-v1.html`，B 使用 `reviewer-b-v1.html`；分别独立完成同一套题目。
- 两人使用同一份 `人工标注手册-零基础完整版.html`。先看开头三步，遇到问题再展开说明，不要求通读。
- 最终按钮为“完成任务并下载结果”。页面只下载到本机，不自动发送；下载后把结果文件发回负责人。
- 中途“保存进度”只保存在当前浏览器。不要以为重新发送 HTML 就会携带已经填写的草稿。

若已经开始填写，先在原页保存并确认成功，再替换原位置的同名文件，继续使用原浏览器与用户配置。不要清理浏览器数据或改用无痕窗口。存储键和结构未改，但浏览器可能限制本地文件存储，因此不能承诺换位置、设备或浏览器后仍自动恢复。

## 改了什么

原来页面同时呈现三栏、内部编号、协议代码、角色字母和完整标注表单。新版按单题组织“看材料 → 标出原文依据 → 作出判断并说明”，把技术字段收进默认关闭的详情。原文采用阅读纸样式、较大字号；手机使用同一顺序。

证据用途和四种结论均有中文名称；事件分组直接问“这是哪一次事情”，解释对应直接问“说明哪次表现”。无关原文不用逐行填满。所需标签、理由、说明和真人声明仍由本人主动填写，不替人选择结论。

比较句不是人物实际原设定。新版主区展示指定来源的实际设定原文，比较坐标仅在可选详情解释，避免简化名词时误导判断方向。

手册源位于 [annotation-reader-guide.md](annotation-reader-guide.md)。教学人物与故事另外虚构，不来自正式材料；判断规则、证据来源与独立完成要求不变。

## 可复现的生成与重发

使用项目虚拟环境运行以下命令。先输出到尚不存在的生成文件；生成器不会覆盖既有输出。

```powershell
.\.venv\Scripts\python.exe scripts/render_annotation_reader_guide.py `
  --output artifacts/annotation-readability-qa/人工标注手册-易读版.html

# 默认只检查，不写文件。目录必须已经包含两份作答页和两份原手册。
.\.venv\Scripts\python.exe scripts/refresh_ooc_annotation_handouts.py `
  --directory <实际发放目录> `
  --guide-html artifacts/annotation-readability-qa/人工标注手册-易读版.html

# 明确 --apply 才会备份并更新四份文件。
.\.venv\Scripts\python.exe scripts/refresh_ooc_annotation_handouts.py `
  --directory <实际发放目录> `
  --guide-html artifacts/annotation-readability-qa/人工标注手册-易读版.html --apply
```

重发工具仅从两份指定 HTML 提取原有公开输入，要求两份输入除标注者身份外完全一致，渲染后再次逐项核对。它不寻找数据包、不读取真人提交或私有答案、不调用模型。所有输出先准备好，再为原四份文件建立不覆盖既有备份的 `原版备份-易读版升级` 目录并核验原字节，然后才替换同名发放文件；原版可从该备份恢复。

## 保持不变的内容

题目正文、顺序、案例与标注者身份、数据集与冻结绑定、`ooc-manual-v1`、草稿存储键与结构、提交 JSON schema、来源限制、四结论条件、两独立事件条件和解释对应规则均不改。真人结果不会因界面更新而被自动重写或作废。

## 验收边界

只使用单独虚构的合成材料检查桌面／手机的阅读与操作，包含必填检查、草稿、提交、身份隔离与离线约束。不让模型代做正式题，也不把软件格式检查解释成“你的剧情判断正确”。当前仍需两位真人的独立结果和之后的分歧处理，才能进入正式质量验收。

网站也遵循[产品文案规范](product-writing-guidelines.md)：普通作者看项目名、文稿名、行号和审查时间；编号、校验值与排错代码按需展开。可追溯性保留，阅读负担不转嫁给作者。

本地交互与发放文件验收已完成。完整网站 CI 的浏览器任务因依赖安装耗时与 10 分钟总时限中断，仅定点重试一次后停止，不当作全套通过；具体失败、修复、取消及其余四项成功记录见[当前阶段状态](current-stage-status.md#2026-10-23-标注与产品语言易读性)。这不改变离线文件不依赖网站或模型的使用方式。
