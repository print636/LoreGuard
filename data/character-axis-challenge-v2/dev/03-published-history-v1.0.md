# 霁汐港｜已发布主线：秋汛之后

秋汛之前，许箬的确不肯独自向陌生水手说明航路。秋汛过后，她自愿参加港务组持续六周的公开领航训练，逐周练习回答临时加入船队者的提问；资深领航员只在前两周陪同。
训练结束的试航日，许箬独自向一船初来港口的水手讲解两处水标的区别，又在无人代答的情况下回应了改道追问。港务组把这一场记录为她已能独立主持公开说明的转折。
去年夜航时，荀木曾因高烧被医师当面要求当日暂停所有热饮，先喝常温水。荀木照做，退烧后又恢复了夜航后喝热姜梅露的习惯；医所把这套临时处置写进她的病历。
同一季的例行试航中，桑衍先把松动护栏的风险告知值守搭档，才调整航路。陆珩请搭档本人在换班表上签名，陈姝对自己误读的潮位负责；这些记录没有改变三人的正式人物基线。
