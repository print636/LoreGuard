# 角色轴跨剧情开发对照集 v1

本集包含两套完全原创的简体中文游戏剧情：`dev`「赤藓层站」与 `transfer`「折云驿」，各有五个交织案例。角色档案与已发布剧情作为权威背景，待审活动稿是可修改的新稿；评测只核对角色一致性判断及原文证据，不要求生成修订文本。

每套正文目前约千余字，专测交织语义、行为归属与情境例外；它不能检验长篇剧情或大量干扰信息下的泛化，后续需另建更长材料。

每套材料的 `review-plan.json` 只保存模拟作者确认正式候选所需的来源锚点、方向、对象和预批准轴定义；`oracle.json` 单独保存草稿证据、预期结论与禁止归属行，仅供模型输出后的评分读取。作者批准轴只适用于核心性格；偏好及其他维度继续使用原有的对象或比较身份规则。`manifest.json` 固定十二个材料与标签文件的 SHA-256，运行前须逐项核验。

这是开发者可见的预注册迁移对照，**不是盲测或生产质量证明**。禁止归属行只用于检查目标角色、目标维度及极性下已接纳信号的可疑归属，不能证明行为语义或总体角色归属准确率；未设正向召回锚点的案例也不评价真实行动者的 trait 抽取召回。首次真实模型运行后，不得根据输出修改既有 Oracle 再追认为独立通过；后续修复可用本集诊断，新的独立质量结论须使用另行预先冻结的材料。旧角色 OOC Oracle 与历史报告不受本集影响。
