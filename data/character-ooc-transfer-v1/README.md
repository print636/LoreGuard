# 雾岬信标节：角色 OOC 迁移对照 V1

本集为原创、开发者可见的迁移对照，不是盲测或生产质量证明。它在第一次真实模型运行前固定正文和 Oracle；此后不以模型输出修改标注。它与潮镜站 DEV 集共享三种判定类别，但角色、世界观和主要性格轴均不同，用来观察改动是否只适配了原样例。

- 霁青：新稿在两个独立日期，无事故或新命令，独自改变队伍撤离路线；预期在正式设定与两条行为证据支持下报角色性格冲突。
- 闻棠：两次公开演示与早期设定相反，但已发布章节记载六周训练；只有提取到观察和已发布桥梁证据后才可判为“已解释”，没有观察不能算正确。
- 舟遥：一次危险时厉声喝止，同稿恢复平时状态；不能将单次紧急行为提升为稳定人格改变。

所有文本均为原创，不包含商业游戏剧情或用户私稿。Oracle 只在模型输出后评分，不上传到服务端或嵌入 Prompt。主流程仍需作者确认正式角色候选；评测脚本的自动确认只允许精确匹配本集预标注的候选。

本集的候选选择器在首次真实模型运行前固定了“原文语义短语 + 特征轴/方向成对允许项”，不能从被测候选自行推导允许轴。未命中允许项应记为验收失败并人工分析，不能在不重新标记本集为开发数据的情况下追加事后选项。
