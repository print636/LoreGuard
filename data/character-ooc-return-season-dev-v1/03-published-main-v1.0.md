# 善潮号｜已发布主线 v1.0

【H01】春季绿讯那晚，七名没有居籍证的船民排在船尾。叶簪发现庆典彩灯船占着避风位，便让彩灯船晚开，亲自把七人的名字补上登船名单，再逐一告诉他们新的船号。
【H02】初夏又是绿讯。贵宾航线与无居籍船民的候船区撞了时间，叶簪把贵宾船推迟半个时辰，向等候的船民说明顺序调整，没有让他们从名单上消失。
【H03】一位伤者不愿自己的姓名出现在回港节目里，迟蘅拒绝了主持人的请求。另一位伤者只准她把姓名和恢复情况告诉指定照护队；迟蘅核对授权后，没把这份记录送往节目组。
【H04】柳泛发现风针卡住，便在当天的公示上写“方向未核实”，原始读数留在观测簿中，复测结果另附一页；出港的人因此知道哪些数字不能当作确定预报。
