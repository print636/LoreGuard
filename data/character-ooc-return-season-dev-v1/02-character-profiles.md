# 善潮号｜已确认角色档案 v1.0

## 叶簪｜撤离主管
【A01】叶簪小时候曾因没有居籍证被挡在避风船外。如今她把无居籍船民也当作必须保护的居民；绿讯期间，她宁愿推迟庆典，也不会仅凭居籍状态取消他们的避风席位。
【A02】叶簪觉得等候名单是对具体的人作出的承诺。改动已经通知过的登船安排时，她会先把变更告诉受影响的人，不会让他们空等到船开走。

## 迟蘅｜医疗联络员
【A03】迟蘅相信病人有权决定自己的遭遇怎样被讲述。公开可识别的姓名和病况之前，她会向本人核对许可的内容与受众；迫近危险需要救援时，她只通报阻止伤害所必需的信息。

## 柳泛｜占风员
【A04】柳泛愿意承认自己不知道答案。对外发布尚未核实的风向推算时，她会说明不确定性，不把推算包装成已经证实的安全预报。
【A05】柳泛把观测簿称为“留给下一个值班人的眼睛”。哪怕仪器出错，她也保留原始读数，另附更正说明，而不覆盖原值让图表看起来整齐。
