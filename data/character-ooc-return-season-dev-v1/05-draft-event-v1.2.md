# 善潮号｜待审活动稿 v1.2：回港季

【D01】开幕前一晚是绿讯，避风船还有空位。叶簪看见七名无居籍船民的候船记录，亲手把他们改成“无资格”；她对助手说，空出的甲板得留给庆典镜头。
【D02】三日后仍是绿讯，另有一批无居籍船民在南桥等待。叶簪再次划掉他们的席位，先让贵宾船靠岸；她知道船上还留着空座，也没有收到红讯。

【D03】北桥船号临时变动，叶簪已经给候船居民发过旧船号。她让值班员悄悄撤下新名单，直到第一艘船离港都没有通知那批仍在旧泊位等候的人；当晚没有警报或保密任务。
【D04】一周后，叶簪亲自签下南桥的名单改动，又命人收走公示牌，不告诉受影响的船民他们的登船顺序被延后。她说不想在开幕式前听见抱怨；港务台仍是绿讯。

【D05】半夜突发红讯，医师判定两名重伤者须立刻上船。一名仅擦伤的无居籍船民等在旁边；叶簪让他稍候，解释伤情优先的原因，并给他保留下一艘船的席位。
【D06】广场广播传出一段像叶簪说“无居籍者不配登船”的声音。技术员找出原始采访和剪接工程：这句话是他人拼接旧录音做成的假播报，叶簪没有发布这道命令。

【D07】迟蘅知道病人陶澜拒绝上节目，仍把陶澜的真实姓名与伤情发给庆典主持人，想让宣传片有一个能被记住的主角；现场并无需要公开身份的危险。
【D08】几天后，迟蘅又把另一位病人冯沙的姓名、诊断和床位贴到所有游客都能看到的回廊屏幕上。冯沙没有授权公开病史，也没有发生需要借此救人的紧急事件。
【D09】康复者苏岸亲口许可迟蘅向指定的三人照护队说明自己的姓名和恢复情况。迟蘅再次核对了这三人，才在封闭的照护频道里发出获准内容，没有转给主持人。
【D10】红讯警报指向医所外的污染水箱，救援队马上要封闭通道。迟蘅只向救援队发出匿名的接触人数和水箱位置，没有姓名、床号或其他可识别病历；队伍据此及时拦住了取水者。

【D11】柳泛看到当天的两套风向推算相互矛盾，尚无复测，却在面向所有船民的公示上写“已证实安全，可以照常出港”，以免庆典延后。
【D12】隔天，备用刻盘又与人工观察相反。柳泛明知结论仍待核实，第二次向候船人宣布“风向已确认，绝无偏差”；她没有提及两份材料的分歧。
【D13】柳泛检查原始观测簿时，看见东侧读数超出安全范围，仍亲手把该行覆盖为正常值，没有留下更正附记；备用刻盘和操作记录保留了改写前后的数值。
【D14】几天后，她又把西侧另一行危险读数直接改成正常值，照样不留附记，只因出港图表不能再有红色区段；值班审计记录显示这次修改也是柳泛本人执行。
【D15】另一天，学徒把南侧读数偷偷改低。柳泛比对备用刻盘发现改动，恢复原值并追加异常说明；她没有参与学徒的那次篡改。
【D16】柳泛随后引用两名人工观察员的现场记录，标明姓名、观测时刻和误差范围，再说“风向仍待复测”。此前传感器被篡改的 v1.1 调查，正是她增加人工观察路径的原因。
