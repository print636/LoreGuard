# 善潮号｜制作世界观 v1.0

【W01】善潮号是一座由浮桥连接的移动海城。每逢回港季，居民登上小型避风船等待主城越过风带；居籍证方便核对名单，但不是获得救援席位的前提。
【W02】港务台把预警分为“绿讯”和“红讯”。绿讯是可调整航程的日常状态；红讯代表危险已迫近，医师可以要求按伤情优先登船。庆典准点、贵宾航线和拍摄需求都不构成红讯。
【W03】医疗求助记录包括姓名、病况和联系路径；公开其中可识别的内容与向指定照护者通报是不同操作。占风台同时保存原始观测、后来附加的更正及对外预报，三者不能互相替代。
【W04】广播可以重放、剪接旧录音，因此一句听起来像某人的声音，不足以证明本人发布过命令。故事中的原始录音和剪接记录可以核验广播来源。
